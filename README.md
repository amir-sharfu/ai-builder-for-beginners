# AI Builder for Beginners

> Learn to build real AI-powered apps — no coding background needed.

This repo is for anyone who wants to build with AI but feels lost when engineers start talking about "React", "APIs", "WebSockets", and "backends". 

You don't need a computer science degree. You need the right mental models — and this repo gives you exactly that.

---

## Who This Is For

- You have zero or very little coding experience
- You want to use AI tools like Claude Code to build real things
- You keep getting stuck because you don't understand *what* the pieces are
- You're tired of tutorials that assume you already know things

---

## How It Works

Each lesson answers **one question** in plain English:
- What is it?
- Real world analogy
- Live website example you can visit right now
- How it shows up in a real app
- What breaks without it
- What to tell AI when you need it
