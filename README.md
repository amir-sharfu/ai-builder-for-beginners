# AI Builder for Beginners

> Learn to build real AI-powered apps — no coding background needed.

This repo is for anyone who wants to build with AI but feels lost when engineers start talking about "React", "APIs", "WebSockets", and "backends".

You don't need a computer science degree. You need the right mental models — and this repo gives you exactly that.

## How Each Lesson is Structured

Every lesson answers **one question** in plain English:

- **One Line Answer** — the simplest possible definition
- **Real World Analogy** — something you already understand
- **Live Example** — a real website you can open right now
- **How It Shows Up in a Real App** — where you'll actually see this
- **What Breaks Without It** — why it matters
- **What to Tell AI** — copy-paste prompts to use with Claude Code

Each lesson shows its **read time** and **difficulty level** so you know what you're committing to before you click.
