# What is GitHub?

> ⏱ 2 min read · 🟡 Intermediate

## One Line Answer
GitHub is a website that hosts Git repositories — it's where code lives online, gets shared, and gets collaborated on.

## Real World Analogy
If Git is the filing system, GitHub is the filing cabinet that everyone can access. Git manages versions locally on your computer. GitHub stores them in the cloud, makes them shareable, and adds collaboration features (issues, pull requests, discussions).

## Live Example
Visit **https://github.com** — you're already here if you're reading this.

GitHub hosts over 300 million repositories. Everything from hobby projects to Linux (which runs most of the world's servers) to the React library itself. Open source software exists because GitHub makes sharing code frictionless.

## GitHub vs Git

| | Git | GitHub |
|--|-----|--------|
| What it is | Software on your computer | Website (cloud service) |
| Purpose | Track changes locally | Host and share repos |
| Requires internet | No | Yes |
| Alternatives | - | GitLab, Bitbucket |

## Key GitHub Features

| Feature | What It Does |
|---------|-------------|
| Repositories | Store and browse code |
| Issues | Track bugs and feature requests |
| Pull Requests | Propose and review code changes |
| Actions | Automate tests and deployments (CI/CD) |
| Codespaces | Run a full dev environment in the cloud |
| Pages | Host static websites for free |
| Stars | Bookmark repos you like |

## GitHub Codespaces
This is how you're likely running this project — GitHub Codespace is a full development environment in the cloud. No local setup needed. Open the repo, click "Codespace", and you have VS Code with a terminal running in a Linux container.
