# Resources for Non-Coders

> ⏱ 2 min read · 🟡 Intermediate

Curated by someone who went through the same confusion. All free unless marked otherwise.

---

## Learning the Web

**https://web.dev/learn** — Google's free web learning platform
Structured courses on HTML, CSS, JavaScript, accessibility. Well written, up to date.

**https://developer.mozilla.org/en-US** — The MDN Web Docs
The reference that developers actually use. When you want to understand exactly what something does, this is where to look.

**https://javascript.info** — The Modern JavaScript Tutorial
The best free resource for learning JavaScript. Starts from zero, goes deep. Patient explanations.

---

## Learning React

**https://react.dev** — Official React Documentation
Completely rewritten in 2023. Has interactive examples and guided tutorials. Start with the "Learn" section.

---

## Learning to Use AI as a Developer Tool

**https://claude.ai** — Use Claude as your personal tutor
Don't just ask it to write code. Ask it to explain things. "Explain closures in JavaScript to someone with no coding background." The explanations are often excellent.

**https://docs.anthropic.com** — Anthropic's documentation
How Claude works, the API, prompt engineering best practices. Readable and practical.

---

## Learning SQL (Databases)

**https://sqlbolt.com** — Interactive SQL tutorial
You learn by writing real queries. No setup needed — runs in the browser. Covers everything you need to know to use a database.

---

## Deploying Apps

**https://railway.app/docs** — Railway documentation
The simplest way to deploy a Node.js + React app. Their docs are clear and beginner-friendly.

**https://render.com/docs** — Render documentation
Alternative to Railway. Free tier available.

---

## Understanding AI

**https://docs.anthropic.com/en/docs/intro-to-claude** — Introduction to Claude
Explains how Claude works, what it can and can't do, and how to get the best results.

**https://www.deeplearning.ai/short-courses** — Short AI courses
Free short courses on AI concepts. "ChatGPT Prompt Engineering for Developers" is directly relevant to what you're doing.

---

## Tools You'll Use Daily

**https://github.com** — Version control and collaboration for all your code

**https://npmjs.com** — Search for packages and read their documentation

**https://stackoverflow.com** — When you search for an error message, Stack Overflow answers often appear. The answers are written by developers for developers, but they're often the fastest path to a fix.

---

## The One Resource That Beats All Others

**Build something.** Every resource on this list accelerates learning that you start by doing. Reading without building is like watching cooking videos without cooking. The taste test is where it gets real.
