# What is Nuxt.js?

> ⏱ 3 min read · 🟢 Beginner

## One Line Answer
Nuxt.js is a tool that helps developers build faster, more organized websites using Vue.js without having to set everything up from scratch.

## Real World Analogy
Think of building a website like cooking a meal. Vue.js gives you the ingredients, but Nuxt.js is like getting a meal kit delivered — the ingredients are already measured, the instructions are clear, and everything is organized so you can skip straight to cooking.

## Live Example
Visit **https://nuxt.com** and click on **"Get Started"** in the top navigation. Notice how the documentation is broken into sections like "Getting Started," "Guide," and "API." This structure mirrors how Nuxt.js itself works — everything has a clear, pre-organized place. Scroll down the homepage to see real companies like GitLab and NASA that use Nuxt.js in production.

## How It Shows Up in a Real App
In a Nuxt.js project, creating a new page is as simple as adding a file to a folder called `pages/`. No extra setup needed.

```
pages/
  index.vue      ← becomes your homepage (/)
  about.vue      ← becomes /about automatically
  contact.vue    ← becomes /contact automatically
```

A developer just creates the file and Nuxt.js handles routing automatically. No extra configuration required.

## What Breaks Without It
Without Nuxt.js, developers would have to manually configure routing, page loading speed, and search engine visibility for every single project from scratch. Tasks that take minutes in Nuxt.js could take hours of custom setup in plain Vue.js.
