# What is a Browser?

> ⏱ 2 min read · 🟢 Beginner

## One Line Answer
A browser is the app you use to view websites — Chrome, Safari, Firefox, and Edge are all browsers.

## Real World Analogy
A browser is like a TV set. The TV doesn't create the shows — it just receives a signal and displays it. Your browser receives code from a server and displays it as a visual webpage.

## Live Example
You are using a browser right now to read this on GitHub.

Open **https://www.youtube.com** in Chrome and then in Safari. The same website, displayed by two different browsers. The content is identical — only the browser is different.

## How It Shows Up in Our App
The frontend of our chat app (the visual part — the chat window, the message list, the input box) lives entirely inside the browser. When you open `http://localhost:5174`, your browser downloads the React app and runs it.

## What Happens Inside a Browser
1. You type a URL
2. Browser asks the server: "Give me this page"
3. Server sends back HTML, CSS, JavaScript files
4. Browser reads those files and draws the page on screen
5. Browser runs the JavaScript to make it interactive

## What Breaks Without It
Without a browser, there's no way to see or interact with the frontend. The code exists, but nothing displays it.

## What to Tell AI When You Need It
> "Build the frontend so it works in a standard web browser. No special apps needed — just open a URL and it should work."
