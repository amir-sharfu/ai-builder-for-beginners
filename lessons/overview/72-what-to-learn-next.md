# What to Learn Next

## You've Covered the Foundation
After this 3-week plan, you understand:
- How the web works (browser ↔ server)
- What HTML, CSS, and JavaScript do
- Frontend (React, Vite, Tailwind) and backend (Node.js, Express)
- APIs, JSON, WebSocket, streaming
- AI integration with the Claude Agent SDK
- How to prompt AI effectively to build real things

That's not beginner knowledge. That's working knowledge of the modern web stack.

## Three Paths Forward

### Path 1: Build More Apps
The fastest way to learn is to build. Pick a project you actually want to exist and build it using what you know. Every problem you hit teaches you more than any lesson could.

**Ideas to try:**
- A personal note-taking app with AI summarisation
- A reading list app where AI can summarise articles
- A daily journal app where AI reflects on your entries
- A meeting notes app that creates action items automatically

---

### Path 2: Go Deeper on the Frontend

If building UIs excites you:

| Topic | Why | Where to Start |
|-------|-----|----------------|
| React in depth | Understand hooks, context, performance | **react.dev** (official docs, excellent) |
| Next.js | Full-stack React framework | **nextjs.org/learn** |
| CSS fundamentals | Understand what Tailwind is abstracting | **https://web.dev/learn/css** |
| TypeScript | Understand the types you're using | **typescriptlang.org/docs/handbook** |

---

### Path 3: Go Deeper on the Backend and AI

If building intelligent systems excites you:

| Topic | Why | Where to Start |
|-------|-----|----------------|
| Databases (SQL) | Store data properly | **sqlbolt.com** (interactive, excellent) |
| Authentication | Let users log in | **clerk.com** (easiest to add) |
| Anthropic API | More control over Claude | **docs.anthropic.com** |
| Prompt Engineering | Better AI results | **https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering** |

---

## The Most Important Advice

**Build something real for yourself.**

The best project is one that solves a real problem you have. You'll be motivated to finish it, you'll use it after it's done, and you'll understand it deeply because you cared about it.

Start small. Ship something. Then improve it.
