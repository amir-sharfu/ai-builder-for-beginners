# Glossary — Plain English Definitions

Every term used in this repo, in one place.

---

**API** — A way for one piece of software to talk to another. The waiter between your app and a service.

**API Key** — A secret password that proves you're authorised to use an API service. Never share it publicly.

**Async/Await** — A way to write code that waits for slow operations (network, disk) without freezing everything else.

**Backend** — The server-side part of an app. Users never see it. It handles data, logic, and external services.

**Browser** — The app you use to visit websites (Chrome, Safari, Firefox, Edge).

**Build** — The process of converting your development code (TypeScript, React) into files the browser can run.

**Class** — A template for creating objects. Like a blueprint for a house — you can build many houses from one blueprint.

**Component** — A reusable UI building block in React. A button, a message bubble, a sidebar.

**Config File** — A file that controls how a tool behaves (vite.config.ts, tsconfig.json, tailwind.config.js).

**CORS** — A browser security rule that blocks requests to different domains unless allowed.

**CSS** — The code that controls how a webpage looks: colors, fonts, spacing, layout.

**Database** — Organised storage for your app's data that persists even after restarts.

**Dependency** — An external package your project relies on.

**Deploy** — Put your app on a real server so anyone on the internet can use it.

**Dev Server** — A local server that runs your app during development (Vite runs on port 5174).

**.env File** — A file storing secret configuration values. Never committed to git.

**Express** — A Node.js framework for building web servers with clean route handling.

**Frontend** — The part of an app that runs in the browser. Everything the user sees and interacts with.

**Framework** — Pre-built code that solves common problems so you don't start from scratch.

**Git** — A tool that tracks every change to your code files and their full history.

**GitHub** — A website that hosts Git repositories and adds collaboration features.

**HTML** — The code that defines the structure and content of a webpage (headings, paragraphs, buttons).

**HTTP** — The protocol browsers use to request and receive web content. One request, one response.

**HTTPS** — Secure HTTP. All data is encrypted between browser and server.

**In-Memory Storage** — Data stored in RAM. Fast, but lost when the process stops.

**JavaScript** — The programming language that makes websites interactive.

**JSON** — A text format for sending structured data between systems.

**Localhost** — The address that means "this computer." `localhost` = `127.0.0.1`.

**Node.js** — A runtime that lets JavaScript run on servers (outside the browser).

**NPM** — Node Package Manager. Downloads and manages external code libraries.

**package.json** — The project's ID card. Lists dependencies, scripts, and project metadata.

**Port** — A numbered door on a computer. Different services listen on different ports.

**Proxy** — Something that sits between two parties and passes requests between them.

**React** — A JavaScript library for building user interfaces out of reusable components.

**Repo (Repository)** — A folder tracked by Git, containing project files and their full change history.

**REST API** — A standard way to design API endpoints using HTTP methods (GET, POST, DELETE).

**Server** — A computer that receives requests and sends back responses.

**State** — Data your app remembers and displays (which chat is open, list of messages).

**Streaming** — Sending data in pieces as it's generated, instead of waiting for it all.

**System Prompt** — Hidden instructions you give an AI that shape how it behaves throughout a conversation.

**Tailwind CSS** — A CSS framework where you style elements using class names directly in HTML.

**Terminal** — A text interface to control your computer by typing commands.

**Token** — The unit AI models use to measure text. Roughly 3/4 of a word. APIs charge per token.

**TypeScript** — JavaScript with type annotations. Catches mistakes before running the code.

**URL** — The address of a resource on the internet.

**Vite** — A frontend build tool and development server for React apps.

**WebSocket** — A persistent, two-way connection between browser and server for real-time communication.
